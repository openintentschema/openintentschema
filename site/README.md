# site

Documentation pages for people who use OIS, as opposed to the specification itself.

- [`getting-started.md`](getting-started.md): from the JUnit XML of an existing pipeline to a
  first OIS bundle (Level 1), about 15 minutes.

Planned sections follow the structure of mature specification sites: Getting started, Learn,
Develop, Specification, Community. There is no site generator yet; the pages are plain Markdown.
