This method computes intent coverage, so that producers who use it report comparable figures.
Other methods remain allowed; each is identified by its own `method` URI. A measurement computed
with this method carries the method URI `https://openintentschema.io/methods/basic-intent-coverage/v0.1`.

:::note[Source]
This method is Appendix D of the
[OIS specification v0.1](https://github.com/openintentschema/openintentschema/tree/main/specification)
(informative). Where this page and the specification differ, the specification applies.

This URI is proposed in
[RFC #6](https://github.com/openintentschema/openintentschema/issues/6). Until that RFC is
decided, the working draft uses the placeholder
`https://ois.example/methods/basic-intent-coverage/v0.1`.
:::

## Inputs

One intent version *v*, one release subject *s* (the code or build artifact being released) and
the criteria in scope: the passport's `scope` entries that belong to *v*, or all criteria of *v*
when `scope` is absent.

## Counted evidence

An evidence record counts if all of the following hold:

- it references a criterion of *v*, or carries over to *v* under the stale evidence rule
  (specification section 6.3);
- its `result` is `pass`;
- its `derivedFrom` is `intent`;
- its `subject` is *s*, or an artifact listed in the `inputs` of *s*;
- it has not been revoked (R11);
- its `observedAt` is later than the `createdAt` of its `subject`.

## Covered criterion

A criterion is covered if at least one counted evidence record references it. A criterion with a
`target` is covered only if that evidence carries a measure whose `name` equals the target's
`metric` and whose `value` satisfies the target's `operator` and `value`.

## Coverage

The number of covered criteria divided by the number of criteria in scope for *v*, reported as a
Measurement named `intentCoverage` with a value between 0 and 1.

## Variants

| Measurement | Difference |
| --- | --- |
| `intentCoverageAttested` | Excludes evidence whose test artifact has a self-declared context (R12). Passports should report both values when they differ. |
| `intentCoverageWeighted` | Weights each criterion by `criticality` (`high` 3, `medium` 2, `low` 1, unset 1) and divides the weight of covered criteria by the total weight. |
| `intentCoverageDiverse` | Counts evidence only when the producers of the test and of the subject are agents on different models (`provider` or `name` differ in every listed model), or when at least one of them is human. It addresses the shared blind spots of agents on the same model, which R5 alone does not catch. |

## Implementation

The reference tools implement this method: `ois passport build` records the four
measurements in a passport's `assessments`, and `ois coverage` recomputes them per criterion and
checks the values a passport declares; see [Build a Quality Passport](/build-a-passport/). It
counts the criteria in scope of all intents a passport lists together.

## Example

In the worked example of the specification, a passport for release 2026.10.3 has two criteria in
scope, AC-1 and AC-2, and counted evidence only for AC-2. Its intent coverage is 0.5:

```json
{ "name": "intentCoverage", "value": 0.5,
  "method": "https://openintentschema.io/methods/basic-intent-coverage/v0.1" }
```
